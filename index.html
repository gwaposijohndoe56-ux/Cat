04 / FIRST-TIME SETUP

FIREBASE CONNECTION CHECKLIST

PROJECT CATTTT-E9023
1. Enable email/password sign-in
  1. Open Firebase Console → Authentication → Sign-in method.
  2. Enable Email/Password and save.
  3. Under Authentication → Users, create the moderator email/password account.
2. Approve the moderator UID

Sign in once. If the account is not yet approved, this app will show its UID. In Realtime Database → Data, create moderators / YOUR_UID = true. The site intentionally cannot approve itself.

3. Add your website domain to Authorized domains

Firebase Console → Authentication → Settings → Authorized domains. Add the exact hostname where this file is hosted (for example, your hosting domain). For local development, add localhost manually if you use it. Firebase Auth will not sign in from a file:// page.

4. Publish these Realtime Database rules

Replace the rules in Realtime Database → Rules with this JSON, then click Publish. It allows the stream page to read the queue and only approved moderator UIDs to change it.


        
5. How to use on two devices
Host this single HTML file on HTTPS. Open the same URL with ?mode=stream on the streamer's screen and ?mode=moderator on the moderator's phone. Both views read the same Firebase Realtime Database and update live.
